🔍 Unsupervised Learning: Autoencoder-Based Clustering Analysis

This project explores unsupervised clustering techniques by combining dimensionality reduction, autoencoders, and clustering evaluation to analyze latent representations of the data.

The work is divided into two main notebooks, each with a clear role in the pipeline.

📁 Notebooks Overview
1️⃣ autoencoder_clusterization.ipynb

This notebook implements the full unsupervised learning pipeline, from raw data to clustering evaluation.

Key steps:

Reproducibility

Seed generation to ensure consistent results.

Data Preparation

Dataset loading and selection of relevant features.

Ordinal encoding of categorical variables.

Visualization of the original feature space using t-SNE.

Autoencoder Implementation

Construction and training of a feedforward autoencoder.

Experimentation with different latent space dimensions.

Use of reconstruction loss (MSE) to evaluate compression quality.

Latent Space Analysis

Visualization of compressed representations using t-SNE.

Comparison between original space and latent space distributions.

Model Selection

Grid search over autoencoder configurations.

Comparison between:

Clustering on original data

Clustering on autoencoder latent representations

Selection of the best-performing model based on clustering behavior.

Clustering Evaluation

Application of the Elbow Method to estimate the optimal number of clusters.

Final testing of clustering results.

2️⃣ cluster_analysis.ipynb

This notebook focuses on post-training analysis of the best model obtained in the previous notebook.

Key steps:

Latent Space Import

Loading the latent representations generated by the selected autoencoder.

Importing the best clustering configuration.

Visualization & Interpretation

Standardized color mapping for consistent cluster visualization.

t-SNE plots to analyze cluster separation and structure.

Interpretation of clustering behavior in the reduced latent space.

This notebook serves as a clean and focused analysis layer, separating experimentation from final interpretation.

🧠 Techniques & Tools Used

Unsupervised Learning

K-Means clustering

Elbow Method

Neural Networks

Autoencoders for dimensionality reduction

Visualization

t-SNE for high-dimensional data exploration

Libraries

Python, NumPy, Pandas

Scikit-learn

TensorFlow / Keras

🎯 Objective

The main goal of this project is to evaluate whether autoencoder-based dimensionality reduction improves clustering performance compared to clustering in the original feature space, and to analyze how latent representations affect cluster separability.
